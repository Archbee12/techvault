# Overview

TechVault Mobile is an Android application I am developing to strengthen my skills in mobile application development, Kotlin programming, database management, and software architecture. The application is part of the broader TechVault Skill Tracker project, which aims to help aspiring software developers organize their technical learning and monitor their progress toward their career goals.

The app is designed to help users manage technical skills and their associated learning goals. Users will be able to organize what they want to learn, track their learning activities, and monitor their progress as they develop new technical competencies.

I created this application to expand my software development experience beyond web applications and explore how mobile applications can provide practical solutions to everyday learning challenges. Through this project, I am gaining hands-on experience with Android development, data persistence, application structure, and integrating software components into a functional product.

# Development Environment

I developed this application using Android Studio as my integrated development environment (IDE). The project uses Gradle with Kotlin DSL for build configuration and dependency management.

The application is written in Kotlin, the primary programming language for the project. The codebase includes components for managing learning goals and database operations, including `LearningGoal.kt`, `GoalDao.kt`, and `TechVaultDatabase.kt`. These components help organize the application's data model and database access.

The project also includes Android resources, an application manifest, and Gradle configuration files needed to build and run the application.
